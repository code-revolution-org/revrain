# Changelog

سيتم توثيق جميع التغييرات المهمة في هذا المشروع في هذا الملف.

يعتمد التنسيق على [Keep a Changelog](https://keepachangelog.com/ar/1.1.0/)، ويلتزم هذا المشروع بـ [التحكم الدلالي بالإصدارات](https://semver.org/lang/ar/).

## [غير مُصدر]

- **استكمال بيانات المؤلف**: محلّل جديد `get-authors.html` كمصدر موحّد لبيانات المؤلف في HTML وJSON-LD وRSS (`.Param "author"`، الصفحة أولًا ثم الرجوع إلى مؤلف الموقع)؛ يدعم صيغ النص والمصفوفة وmap، بالإضافة إلى عدة مؤلفين ببريد إلكتروني مختلط؛ تغيّر `author` في JSON-LD من Organization ثابتة إلى Person (مصفوفة عند تعدد المؤلفين)
- **إصلاح توطين التواريخ الصينية**: تغيّر `locale` إلى `zh-Hans-CN` / `zh-Hant-TW` (فـ`golocales` لا يدعم `zh-CN`/`zh-TW`، مما جعل التواريخ ترجع إلى الإنجليزية)؛ تم تحديث `<html lang>` وhreflang و`og:locale` و`<language>` في RSS وفقًا لذلك
- **توحيد تنسيق Markdown**: طبقة `.markdown` جديدة تجمع ثلاث مجموعات مكرّرة من قواعد النص؛ كل قالب صفحة يغلّف `.Content`؛ توحيد حجم `<h1>` وارتفاع سطره
- **خطاف عرض الاقتباس**: البنية مطابقة لافتراضي Hugo، مع دعم سمات كتل Markdown
- **إصلاح اختلال الاقتباس**: كان ارتفاع خط التمييز وصندوق الخلفية غير متساوٍ (حشو أفقي فقط وهوامش الفقرة الداخلية)
- **اتساق التنقل**: إضافة زر الرجوع ومسار التنقل إلى صفحات التصفح والتصنيفات وحول؛ ويصون `breadcrumb.html` الآن الحالة الفارغة لـ `.Ancestors` (صفحات نظرة عامة على التصنيفات) ويوفّر بديلاً عند فراغ العنوان
- **صفحة حول**: إزالة `.about__content` لصالح طبقة `.markdown` المشتركة (تغيير كاسر)

## [v0.0.1] - 2026-09-10

أول إصدار رسمي من revrain.

### Added

- **هيكل القالب**: قالب Hugo داكن متكامل مع قوالب للصفحة الرئيسية وصفحة «حول» وصفحة التصفح وصفحة 404 والمقالات/الأقسام
- **المطر الرقمي**: رسم متحرك من نوع Matrix على Canvas؛ مجموعة الأحرف وحجم الخط واحتمال اللون الأبيض القمري واحتمال إعادة الضبط كلها قابلة للتخصيص. يحترم إعداد النظام «تقليل الحركة» (يرسم إطارًا ثابتًا واحدًا) ويتخطى الإطارات تلقائيًا على الأجهزة الضعيفة
- **الزجاج المثلّج**: بطاقات زجاجية مصنفرة عبر تمويه backdrop-filter
- **تعدد اللغات**: 11 لغة مدمجة (zh-CN / zh-TW / en-US / ja / ko / de / fr / es / pt-BR / ru / ar)، الصينية المبسطة افتراضيًا؛ محوّل لغة قابل للاستخدام بلوحة المفاتيح (الأسهم، Home/End، Esc)
- **تحسين محركات البحث SEO**: description / robots / canonical / روابط بديلة hreflang، ترقيم rel=prev/next، Open Graph، Twitter Card، بيانات منظمة JSON-LD (WebSite / Article)، مخطط مسار التنقل، سلسلة بحث og:image مع اكتشاف تلقائي للصور الغلافية
- **إمكانية الوصول (WCAG 2.2 AA)**: رابط الانتقال إلى المحتوى الرئيسي، معالم وتسميات ARIA، التنقل بلوحة المفاتيح، تركيز مرئي، دعم prefers-reduced-motion، تخطيط RTL معكوس للعربية
- **التجاوب**: أسلوب الجوال أولًا مع 4 نقاط توقف (480 / 768 / 1024 / 1280px)
- **دعم المعادلات الرياضية**: عرض من جانب الخادم وقت البناء عبر KaTeX المدمج في Hugo (`transform.ToMath`)؛ دون حاجة إلى JS من جانب العميل
- **تلوين الصيغ البرمجية**: دعم مدمج عبر Hugo
- **RSS**: خلاصات للصفحة الرئيسية والأقسام، مع معلومات عدة مؤلفين ونقطة اشتراك ذكية
- **التصنيفات**: سحب الوسوم/الفئات مع ترقيم من جانب الخادم
- **جدول المحتويات**: TOC في الشريط الجانبي مع تمييز عند التمرير وعناصر متداخلة قابلة للطي
- **التنقل**: مسار التنقل، زرا السابق/التالي، زر الرجوع
- **favicon**: مجموعة أيقونات قياسية متعددة التنسيقات (SVG / 16 / 32 / apple-touch) مع سلسلة بدائل من ثلاثة مستويات
- **حزمة الخطوط**: خطوط مفتوحة المصدر تغطي جميع اللغات التي يدعمها القالب (اللاتينية، CJK، العربية، السيريلية)
- **النشر**: بناء تلقائي عبر GitHub Actions ونشر على GitHub Pages
- **الموقع النموذجي**: صفحات رئيسية و«حول» وتصفح وأقسام بـ 11 لغة، بالإضافة إلى 5 مقالات تعليمية متعددة اللغات
- **الحد الأدنى من المتطلبات**: Hugo >= 0.163.0 (أي إصدار)، Dart Sass
