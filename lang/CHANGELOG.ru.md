# Changelog

Все значимые изменения этого проекта будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а этот проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Не выпущено]

- **Дополнены данные об авторе**: новый резолвер `get-authors.html` как единый источник данных об авторе для HTML, JSON-LD и RSS (`.Param "author"`, сначала страница, затем автор сайта); поддерживаются строки, массивы и map, а также несколько авторов со смешанными адресами; `author` в JSON-LD изменён с жёстко заданной Organization на Person (массив для нескольких авторов)
- **Исправлена локализация дат на китайском**: `locale` изменён на `zh-Hans-CN` / `zh-Hant-TW` (`golocales` не поддерживает `zh-CN`/`zh-TW`, из-за чего даты отображались по-английски); `<html lang>`, hreflang, `og:locale` и `<language>` в RSS обновлены соответственно
- **Единая типографика Markdown**: новый слой `.markdown`, объединивший три дублирующихся набора правил для текста; все шаблоны страниц оборачивают `.Content`; размер и межстрочный интервал `<h1>` унифицированы
- **Хук отрисовки цитат**: структура совпадает со стандартной в Hugo, поддерживаются блочные атрибуты Markdown
- **Исправлено смещение цитат**: линия выделения и фон имели разную высоту (отступы только по горизонтали плюс внешний отступ внутреннего `<p>`)
- **Согласованная навигация**: кнопка «назад» и «хлебные крошки» добавлены на страницы обзора, таксономии и «о проекте»; `breadcrumb.html` теперь проверяет пустой `.Ancestors` (страницы обзора таксономии) и подставляет запасной заголовок
- **Страница «о проекте»**: удалён `.about__content` вместо общего слоя `.markdown` (обратно несовместимое изменение)

## [v0.0.1] - 2026-09-10

Первый официальный релиз revrain.

### Added

- **Каркас темы**: полная тёмная тема Hugo с шаблонами главной страницы, страницы «О сайте», страницы обзора, страницы 404, а также статей и разделов
- **Цифровой дождь**: Canvas-анимация в стиле «Матрицы»; набор символов, размер шрифта, вероятность лунно-белого символа и вероятность сброса полностью настраиваются. Учитывает системную настройку «уменьшить движение» (рисует один статический кадр) и автоматически пропускает кадры на слабых устройствах
- **Glassmorphism**: карточки из матового стекла с размытием backdrop-filter
- **Многоязычность**: встроены 11 языков (zh-CN / zh-TW / en-US / ja / ko / de / fr / es / pt-BR / ru / ar), по умолчанию — упрощённый китайский; переключатель языка, управляемый с клавиатуры (стрелки, Home/End, Esc)
- **SEO**: description / robots / canonical / альтернативные ссылки hreflang, пагинация rel=prev/next, Open Graph, Twitter Card, структурированные данные JSON-LD (WebSite / Article), схема хлебных крошек, цепочка поиска og:image с автоматическим обнаружением обложек
- **Доступность (WCAG 2.2 AA)**: ссылка перехода к основному контенту, ARIA-ориентиры и подписи, навигация с клавиатуры, видимый фокус, поддержка prefers-reduced-motion, зеркальная RTL-вёрстка для арабского языка
- **Адаптивность**: mobile-first с 4 контрольными точками (480 / 768 / 1024 / 1280px)
- **Математические формулы**: серверный рендеринг на этапе сборки с помощью встроенного в Hugo KaTeX (`transform.ToMath`); без JS на клиенте
- **Подсветка синтаксиса**: встроенная поддержка Hugo
- **RSS**: ленты для главной страницы и разделов, с информацией о нескольких авторах и умной точкой подписки
- **Таксономии**: облака тегов/категорий с серверной пагинацией
- **Оглавление**: TOC в боковой панели с подсветкой при прокрутке и сворачиваемыми вложенными элементами
- **Навигация**: хлебные крошки, кнопки «предыдущая/следующая», кнопка «назад»
- **favicon**: стандартный мультиформатный набор иконок (SVG / 16 / 32 / apple-touch) с трёхуровневой цепочкой запасных вариантов
- **Системный стек шрифтов**: открытые шрифты, покрывающие все поддерживаемые темой языки (латиница, CJK, арабский, кириллица)
- **Развёртывание**: автоматическая сборка GitHub Actions и публикация на GitHub Pages
- **Примерный сайт**: главные страницы, страницы «О сайте», обзора и разделов на 11 языках, а также 5 многоязычных обучающих статей
- **Минимальные требования**: Hugo >= 0.163.0 (любая редакция), Dart Sass
