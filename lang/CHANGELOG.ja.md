## [v0.0.1] - 2026-09-10

revrain の最初の正式リリース。

### Added

- **テーマフレームワーク**：ホームページ、アバウトページ、ブラウズページ、404 ページ、記事・セクションのテンプレートを含む完全なダークテーマ
- **デジタルレイン**：Matrix 風 Canvas アニメーション。文字セット、フォントサイズ、月白色の確率、リセット確率をすべて設定可能。システムの「視差効果を減らす」設定に従い（静的フレームのみ描画）、低スペック端末では自動でフレームを間引く
- **ガラスモーフィズム**：backdrop-filter のブラーによるすりガラス風カード
- **多言語**：11 言語を内蔵（zh-CN / zh-TW / en-US / ja / ko / de / fr / es / pt-BR / ru / ar）、既定は簡体字中国語。キーボード操作可能な言語切替（矢印キー、Home/End、Esc）
- **SEO**：description / robots / canonical / hreflang 代替リンク、ページネーション rel=prev/next、Open Graph、Twitter Card、JSON-LD 構造化データ（WebSite / Article）、パンくずスキーマ、og:image 検索チェーンとカバー画像の自動検出
- **アクセシビリティ（WCAG 2.2 AA）**：メインコンテンツへのスキップリンク、ARIA ランドマークとラベル、キーボードナビゲーション、可視フォーカス、prefers-reduced-motion 対応、アラビア語 RTL ミラーレイアウト
- **レスポンシブ**：モバイルファースト、4 つのブレークポイント（480 / 768 / 1024 / 1280px）
- **数式サポート**：ビルド時に Hugo 内蔵の KaTeX（`transform.ToMath`）でサーバーサイドレンダリング。クライアント側 JS 不要
- **シンタックスハイライト**：Hugo 内蔵
- **RSS**：ホームページとセクションのフィード、複数著者の情報とスマートな購読エントリーに対応
- **分類法**：タグ / カテゴリーのクラウド。サーバーサイドページネーションを使用
- **目次（TOC）**：サイドバーの目次、スクロール追従ハイライト、折りたたみ可能なネスト項目
- **ナビゲーション**：パンくずリスト、前後の記事ボタン、戻るボタン
- **favicon**：標準のマルチフォーマットアイコンセット（SVG / 16 / 32 / apple-touch）と 3 段階のフォールバックチェーン
- **フォントシステムスタック**：テーマが対応するすべての言語をカバーするオープンソースフォント（ラテン、CJK、アラビア、キリル）
- **デプロイ**：GitHub Actions による自動ビルドと GitHub Pages へのデプロイ
- **サンプルサイト**：11 言語のホーム・アバウト・ブラウズ・セクションページと 5 本の多言語チュートリアル記事
- **最小要件**：Hugo >= 0.163.0（通常版で可）、Dart Sass
