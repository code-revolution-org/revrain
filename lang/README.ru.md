# revrain

Тема Hugo от [Code Revolution](https://github.com/code-revolution-org), созданная для гиков и разработчиков. Тёмный дизайн с цифровым дождём и эстетикой матового стекла (glassmorphism).

[简体中文](../README.md) | [English](README.en-US.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [العربية](README.ar.md)

## Возможности

- **Цифровой дождь** — Canvas-анимация в стиле «Матрицы»; набор символов, размер шрифта, вероятность лунно-белого символа и вероятность сброса полностью настраиваются. Учитывает системную настройку «уменьшить движение» (рисует один статический кадр) и автоматически пропускает кадры на слабых устройствах
- **Glassmorphism** — Матовые стеклянные карточки с размытием backdrop-filter
- **Многоязычность** — 11 встроенных языков, с доступным с клавиатуры переключателем языка (стрелки, Home/End, Esc)
- **SEO** — description / robots / canonical / альтернативные ссылки hreflang, rel=prev/next пагинации, Open Graph, Twitter Card, структурированные данные JSON-LD (WebSite / Article), схема хлебных крошек
- **Адаптивность** — Mobile-first, 4 точки останова (480 / 768 / 1024 / 1280px)
- **Подсветка синтаксиса** — Встроенная через Hugo
- **Поддержка математики** — Серверный рендеринг встроенным KaTeX от Hugo (`transform.ToMath`) во время сборки; без JS на клиенте
- **Тёмная тема** — Палитра, оптимизированная для разработчиков (5 цветов)
- **Доступность** — Соответствие WCAG 2.2 AA: ссылка перехода к основному содержимому, ARIA-ориентиры и подписи, навигация с клавиатуры, видимый фокус, поддержка prefers-reduced-motion, RTL-раскладка (арабский)
- **RSS** — Ленты для главной страницы и разделов
- **Оглавление** — Боковая TOC с подсветкой при прокрутке и сворачиваемыми вложенными элементами
- **Серверная пагинация** — Для разделов, таксономий и облака тегов

## Быстрый старт

Включите тему в конфигурации вашего сайта:

```toml
theme = "revrain"
```

## Конфигурация

### Глобальные параметры

```toml
[params]
  logo = "/logo.png"          # Логотип в навигационной панели (необязательно)
  description = "..."         # Описание сайта для SEO
  images = ["/og-image.png"]  # Изображение по умолчанию для соцсетей

[params.social]
  twitter = "username"        # Аккаунт Twitter для twitter:site

[params.favicons]             # Иконки вкладки браузера (все необязательны)
  svg = "/favicon.svg"                # Векторная иконка SVG
  icon_32 = "/favicon-32x32.png"      # 32x32 PNG
  icon_16 = "/favicon-16x16.png"      # 16x16 PNG
  apple_touch = "/apple-touch-icon.png"  # Иконка главного экрана iOS
```

**Цепочка поиска favicon:** каждый элемент разрешается как *настроенный путь → стандартное имя файла в `static/` → пропуск*. Если ничего не настроено и файлов нет, выводится пустой `data:` URI для подавления стандартного запроса браузера к `/favicon.ico` (без 404). Пути могут быть внешними URL или относительными путями сайта.

### Подвал

```toml
[params.footer]
  github = "https://github.com/username"          # Ссылка GitHub (необязательно)
  copyright = "Мой блог · Все права защищены"     # Копирайт (необязательно, скрыт если не задан)

  [[params.footer.links]]                         # Группа ссылок (необязательно)
    name = "Название ссылки"
    identifier = "friendly_links"                 # Необязательно: ключ i18n, перевод приоритетен
    url = "https://example.com"
```

**Поведение копирайта:**
- Не настроен → не отображается
- Настроен → выводится как `© <текущий год> <значение>` (год обновляется автоматически)
- Многоязычные сайты: настраивается отдельно для каждого языка (см. «Многоязычность»)

### Цифровой дождь

```toml
[params.digital_rain]
  enable = true
  chars = "アイウエオカキクケコ0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
  font_size = 14       # 10–32 px
  moon_chance = 0.02   # Вероятность лунно-белого символа (0–1)
  reset_chance = 0.025 # Вероятность сброса капли (0–1)
```

### Математика

Формулы рендерятся во время сборки встроенным движком KaTeX от Hugo (`transform.ToMath`) как HTML + MathML — без JavaScript на клиенте. Включите расширение Goldmark passthrough в конфигурации:

```toml
[markup.goldmark.extensions.passthrough]
  enable = true
  [markup.goldmark.extensions.passthrough.delimiters]
    block = [['\[', '\]'], ['$$', '$$']]
    inline = [['\(', '\)']]
```

Используйте эти разделители в содержимом:

- В строке: `\(...\)`
- Блок: `$$...$$` или `\[...\]`

**Примечание о CDN:** Таблица стилей KaTeX (`katex.min.css` v0.17.0, требуется для вывода `htmlAndMathml`) загружается с CDN jsDelivr с проверкой целостности субресурсов (SRI). KaTeX распространяется по [лицензии MIT](https://github.com/KaTeX/KaTeX/blob/main/LICENSE). Она загружается только на страницах, содержащих математику.

### Многоязычность

Проект поддерживает 11 языков, упрощённый китайский — язык по умолчанию. Для каждого языка можно задать `label` (отображаемое имя), `locale` (RFC 5646), `title` (заголовок сайта), `weight` (порядок сортировки, по возрастанию) и параметры конкретного языка:

```toml
defaultContentLanguage = 'zh-CN'

[languages]
  [languages.zh-CN]
    label = "简体中文"
    locale = 'zh-CN'
    title = '我的站点'
    weight = 10
    [languages.zh-CN.params.footer]
      copyright = "我的博客 · 版权所有"

  [languages.en-US]
    label = "English"
    locale = 'en-US'
    title = 'My Site'
    weight = 20
    [languages.en-US.params.footer]
      copyright = "My Blog · All Rights Reserved"

  [languages.ar]
    label = "العربية"
    locale = 'ar'
    direction = 'rtl'   # Раскладка справа налево для арабского
    title = 'موقعي'
    weight = 30
```

Содержимое назначается языкам по суффиксу имени файла; суффикс должен быть в нижнем регистре (например, `about.en-us.md`, `about.zh-cn.md`). Файлы без суффикса принадлежат языку по умолчанию.

### Меню

```toml
[[menus.main]]
  name = "Главная"
  identifier = "menu_home"  # Ключ i18n (необязательно); перевод приоритетен
  pageRef = "/"
  weight = 10
```

## Содержимое

### Главная страница

Главная страница использует `_index.md` и поддерживает следующее front matter:

```markdown
+++
title = "Мой сайт"              # Заголовок страницы
subtitle = "Добро пожаловать на мой сайт"  # Подзаголовок под заголовком
logo = "/logo.png"             # Логотип главной страницы (необязательно)
logo_alt = "Логотип сайта"     # Альтернативный текст логотипа (доступность)

[primary_button]               # Основная кнопка
  url = "/browse"
  text = "Начать"

[secondary_button]             # Дополнительная кнопка
  url = "/about"
  text = "О нас"
+++

Текст главной страницы, отображается в стеклянной карточке под кнопками.
```

### Страница «О нас»

Отдельная страница с `layout = "about"`:

```markdown
+++
title = "О нас"                 # Заголовок страницы
layout = "about"               # Использовать шаблон «О нас»
subtitle = "Меняем мир с помощью кода"  # Подзаголовок
avatar = "/avatar.png"         # Изображение аватара (необязательно)
description = "Описание сайта для SEO"  # SEO-описание

links = [                      # Социальные/внешние ссылки (необязательно)
  { name = "GitHub", url = "https://github.com/username" },
  { name = "Twitter", url = "https://twitter.com/username" }
]
+++

Текст страницы «О нас».
```

### Статьи

Обычные статьи (внутри каталога раздела) поддерживают следующее front matter:

```markdown
+++
title = "Моя статья"            # Заголовок статьи
date = 2025-01-15              # Дата публикации
draft = false                  # Черновик: пропускается при true
tags = ["технологии", "hugo"]  # Теги (необязательно)
categories = ["Учебник"]       # Категории (необязательно)
summary = "Краткое описание статьи на карточках"  # Краткое описание для списка
description = "SEO-описание; используется краткое описание, если не задано"  # SEO-описание
+++

Текст статьи.
```

### Страница обзора

Страница с `layout = "directory"`, перечисляющая все разделы:

```markdown
+++
title = "Обзор"                 # Заголовок страницы
layout = "directory"           # Использовать шаблон каталога
description = "Просмотр всех разделов и статей"  # SEO-описание
+++
```

### Разделы

Каждый раздел определяется через `_index.md`; `summary` отображается на карточках:

```markdown
+++
title = 'Статьи'                # Заголовок раздела
summary = 'Статьи о технологиях, жизненных эссе и многом другом.'  # Краткое описание на карточках
+++
```

## Доступность (WCAG 2.2)

- Ссылка перехода к основному содержимому (WCAG 2.4.1)
- ARIA-ориентиры и подписи: основная навигация, навигация подвала, навигация страницы, переключатель языка (role=listbox)
- Полная поддержка клавиатуры для переключателя языка: стрелки для перемещения фокуса, Home/End, Esc для закрытия
- Кнопка мобильного меню раскрывает `aria-expanded` / `aria-controls`
- Canvas цифрового дождя скрыт от вспомогательных технологий (`aria-hidden`, чисто декоративный) и учитывает prefers-reduced-motion
- Подсветка при прокрутке и сворачивание TOC полностью управляются с клавиатуры
- Автоматическая RTL-раскладка для арабского (ar)
- Видимые стили фокуса и глобальная поддержка prefers-reduced-motion
