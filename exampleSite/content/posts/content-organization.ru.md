## Главная страница

`content/_index.md` поддерживает заголовок, подзаголовок, logo и две кнопки:

```toml
+++
title = "Мой сайт"
subtitle = "Добро пожаловать на мой сайт"
logo = "/logo.png"
logo_alt = "Логотип сайта"

[primary_button]
url = "/browse"
text = "Начать обзор"

[secondary_button]
url = "/about"
text = "О сайте"
+++

Текст главной страницы, отображается в стеклянной карточке под кнопками.
```

`logo`, `logo_alt` и кнопки — все необязательны; отсутствующие элементы не отображаются.

## Страница «О сайте»

`content/about.ru.md`, объявите `layout = "about"`:

```toml
+++
title = "О сайте"
layout = "about"
subtitle = "Меняем мир кодом"
avatar = "/avatar.png"
description = "SEO-описание страницы"
links = [
  { name = "GitHub", url = "https://github.com/username" }
]
+++
```

`avatar` и `links` необязательны. `links` отображается как список внешних ссылок с автоматически добавленными `target="_blank" rel="noopener"`.

## Страница обзора

`content/browse.ru.md`, объявите `layout = "directory"`, который автоматически перечисляет все разделы:

```toml
+++
title = "Обзор"
layout = "directory"
description = "Просмотр всех разделов и статей"
+++
```

## Раздел

Индекс раздела `content/posts/_index.md`, `summary` отображается в списке карточек:

```toml
+++
title = "Статьи"
summary = "Коллекция статей о технологиях, жизненных эссе и многом другом."
+++
```

## Статьи

`content/posts/my-post.ru.md`, обычным статьям не нужен `layout`:

```toml
+++
title = "Моя статья"
date = 2026-09-09
draft = false
tags = ["технологии", "hugo"]
categories = ["руководство"]
summary = "Краткое описание статьи, отображается в списке карточек"
description = "SEO-описание, используется краткое описание если не задано"
+++

Текст статьи.
```

Страницы статей автоматически отображают оглавление в боковой панели (TOC), хлебные крошки и навигацию к предыдущей/следующей статье. `summary` наполняет карточку списка; `description` служит для SEO и использует `summary`, если не задано.
