## Язык по умолчанию

```toml
defaultContentLanguage = 'zh-CN'
```

Файлы контента без языкового суффикса относятся к языку по умолчанию.

## Определения языков

```toml
[languages]
  [languages.zh-CN]
    label = "简体中文"
    locale = 'zh-CN'
    title = 'Мой сайт'
    weight = 10

  [languages.en-US]
    label = "English"
    locale = 'en-US'
    title = 'My Site'
    weight = 20

  [languages.ar]
    label = "العربية"
    locale = 'ar'
    direction = 'rtl'
    title = 'موقعي'
    weight = 30
```

- `label`: отображаемое имя в переключателе языка
- `locale`: языковой тег RFC 5646, используется для `<html lang>` и hreflang
- `weight`: возрастающий порядок задаёт порядок переключателя
- `direction = "rtl"`: арабский автоматически включает порядок справа налево

## Именование файлов контента

Языки различаются суффиксом имени файла, который **должен быть в нижнем регистре**:

| Файл | Язык |
| --- | --- |
| `about.zh-cn.md` | 简体中文 |
| `about.en-us.md` | English |
| `about.ar.md` | العربية |

Суффикс можно опустить для языка по умолчанию; например, когда по умолчанию `zh-CN`, `about.md` эквивалентно `about.zh-cn.md`.

Файлы с одинаковым базовым именем, но разными суффиксами в одном разделе автоматически связываются как переводы, и тема выводит соответствующие hreflang-альтернативы.

## Параметры по языкам

Можно настроить параметры для каждого языка, например копирайт в футере:

```toml
[languages.zh-CN.params.footer]
  copyright = "Мой блог · Все права защищены"

[languages.en-US.params.footer]
  copyright = "My Blog · All Rights Reserved"
```

Переключатель языка — выпадающее меню с полной поддержкой клавиатуры: стрелки перемещают фокус, `Home`/`End` переходят к первому/последнему элементу, `Esc` закрывает.
