## Включение

```toml
[params.digital_rain]
enable = true
```

Установите `false`, чтобы полностью отключить холст.

## Набор символов

```toml
[params.digital_rain]
chars = "アイウエオカキクケコ0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
```

Подойдёт любая строка; символы случайно извлекаются в каждом столбце.

## Полные параметры

```toml
[params.digital_rain]
enable = true
chars = "アイウエオ0123456789ABC"
font_size = 14        # 10–32, в px
moon_chance = 0.02    # вероятность лунно-белого символа, 0–1
reset_chance = 0.025  # вероятность сброса капель, 0–1
```

- `font_size`: размер шрифта, диапазон 10–32
- `moon_chance`: вероятность, что символ появится в лунно-белом цвете (акцентный цвет)
- `reset_chance`: вероятность возврата капли наверх; чем выше значение, тем быстрее поток

## Поведение доступности

Холст скрыт от вспомогательных технологий (`aria-hidden`, чисто декоративный). Когда система включает «уменьшение движения» (`prefers-reduced-motion: reduce`), рисуется только статичный кадр; маломощные устройства автоматически пропускают кадры, чтобы снизить нагрузку.
